🛠 Инструменты VPS

Здесь собраны команды и приёмы, которые реально полезны для работы на сервере:

  • ls — посмотреть файлы и папки
  • cd — перейти в папку
  • mkdir — создать папку
  • touch — создать пустой файл
  • cat — посмотреть содержимое файла
  • nano — редактировать файл
  • chmod — дать права на файл
  • sudo — выполнить команду с правами администратора
  • ssh — подключение к серверу

Все эти команды пригодятся для автоматизации, настройки VPS и поднятия своих сервисов.
