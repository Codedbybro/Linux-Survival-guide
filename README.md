# 🛡️ Survival Guide

> **A practical IT guide for learning and working with Linux, VPS, Bash, and server infrastructure.**

Survival Guide is an informational web project containing practical materials about Linux servers, VPS, Bash, and various tools used when working with servers and IT infrastructure.

The project is designed not just as a collection of theory, but as a **practical reference** that can be used whenever you need to quickly remember a command, understand a concept, or find a solution to a common server-related task.

## 🖥️ Project Concept

The main goal of Survival Guide is to collect useful information in one place.

Instead of searching the internet every time for things like:

```text
"How do I check a port?"
"How do I connect to a VPS?"
"How do I check running processes?"
"Which Linux command should I use?"
```

you can open Survival Guide and find the relevant information in the appropriate section.

The project focuses on **practical knowledge that can actually be used while working with servers and Linux systems.**
